## Этап 1: Backend (Laravel API)

- [x] Установить Laravel 11 в папку `backend/`
- [x] Настроить `.env` (SQLite для dev)
- [ ] Выбрать и настроить БД (MySQL — production, SQLite — dev)

### 1.2. Аутентификация (Sanctum)
- [x] Установить Laravel Sanctum
- [x] Регистрация (register)
- [x] Вход (login)
- [x] Выход (logout)
- [x] Текущий пользователь (`GET /api/user`)
- [x] Middleware — защита API-роутов

### 1.3. Модели и миграции
- [x] **Account** — id, name, balance, currency, color, icon, user_id
- [x] **Category** — id, name, type (expense/income), icon, color, user_id
- [x] **Tag** — id, name, user_id
- [x] **Transaction** — id, account_id, category_id, amount, type, date, comment, photo_path, user_id
- [x] **TransactionTag** — transaction_id, tag_id (pivot)
- [x] **RecurringPayment** — id, user_id, account_id, category_id, amount, type, frequency, next_date, active

### 1.4. API — Категории
- [x] CRUD категорий (GET / POST / PUT / DELETE)
- [x] Только свои категории (scope by user_id)

### 1.5. API — Счета
- [x] CRUD счетов
- [x] Баланс: вычисляется на основе транзакций, а не хранится вручную

### 1.6. API — Транзакции

### 1.7. API — Аналитика (главный экран)

### 1.8. Теги
